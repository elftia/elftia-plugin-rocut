The exact FFmpeg source and upstream build-recipe archives accompany this directory.
The build recipe includes dependency source locations, versions, patches and build scripts.
Sources are also available from https://github.com/FFmpeg/FFmpeg and
https://github.com/BtbN/FFmpeg-Builds at the revisions above.

The complete original upstream binary ZIP is retained in the producer repository's
build-inputs/offline-decoders directory, together with its pinned SHA-256 provenance.
Package assembly verifies that local archive and needs no live nightly URL or PATH.
Assembly reproducibility means byte-exact projection from these archived build inputs;
it does not claim a fresh compiler run reproduces upstream executable bytes.

The decoder is a separate executable with replaceable shared libraries. This plugin
does not restrict reverse engineering or modification of the LGPL components.
Changing those files requires rebuilding the package and refreshing its integrity
metadata; package integrity verification applies equally to all bundled runtime files.
